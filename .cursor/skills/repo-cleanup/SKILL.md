# Skill: Repository Cleanup Assistant (GitHub MCP)

## Goal
Keep repository clean and optimized.

## When to trigger
- On request or periodically

## Use MCP tools
- search_code
- list_branches

## Behavior
- Find:
  - unused files
  - large files
  - debug leftovers
- Suggest:
  - removal
  - refactor

## Output
- Cleanup report
